# C# Interpolation Tables

Generated by `python export_tables.py`.  All values are SI units unless noted.

## `wing_aero.json`

Flat object — Unity `JsonUtility` compatible.

```
{
  "span": 1.5,              // wing span [m]
  "area": 0.3,              // planform area [m²]
  "AR": 7.5,                // aspect ratio
  "CL_max": 1.3174,         // peak lift coefficient
  "alpha_stall_deg": 16.83, // stall angle [deg]
  "V_stall": 9.0,           // stall speed at mass_ref_kg [m/s]
  "mass_ref_kg": 2.0,       // reference mass for V_stall
  "rho": 1.225,             // air density [kg/m³]
  "n_pts": 91,              // length of alpha_deg / CL / CD arrays

  "alpha_deg": [ -10.0, -9.611, … ],   // 91 values, sorted ascending
  "CL":        [ -0.79,  … ],          // lift coefficient at each α
  "CD":        [ 0.035,  … ]           // total drag coefficient at each α
}
```

**C# interpolation:**
```csharp
float CL = Mathf.Lerp(table.CL[i], table.CL[i+1], t);  // where alpha is between table.alpha_deg[i] and [i+1]
float CD = Mathf.Lerp(table.CD[i], table.CD[i+1], t);
// Beyond table range: hold edge values (post-stall) or extrapolate with thin-airfoil slope (below min).
```

## `propulsion.json`

2D grid: thrust and power as functions of airspeed and throttle at fixed blade pitch.

```
{
  "diameter_m": 0.254,      // propeller diameter [m]  (~10 inch)
  "n_blades": 2,
  "pitch_deg": 4.0,         // blade pitch [deg]
  "max_rpm": 9550.0,        // motor RPM at full throttle
  "idle_rpm": 0.0,
  "rho": 1.225,
  "n_V": 36,                // number of airspeed points
  "n_throttle": 21,         // number of throttle points
  "V_min": 0.5,             // minimum airspeed in table [m/s]
  "V_max": 35.0,            // maximum airspeed in table [m/s]

  "V":        [ 0.5, 1.485, … ],         // 36 values, sorted, [m/s]
  "throttle": [ 0.0, 0.05, 0.10, … ],    // 21 values, [0, 1]
  "thrust":   [ [row0…], [row1…], … ],   // 36×21, thrust [N],   index = V × throttle
  "power":    [ [row0…], [row1…], … ]     // 36×21, shaft power [W]
}
```

Grid convention (C-order, row-major): `thrust[i][j]` = thrust at `V[i]`, `throttle[j]`.

Values are clamped to ≥ 0; the raw BEMT can produce negative thrust (windmilling) at high advance ratios, but flight loops typically treat negative thrust as zero.

**C# bilinear interpolation:**
```csharp
// 1. Find indices: V is between table.V[iv] and table.V[iv+1]
//                  throttle is between table.throttle[it] and table.throttle[it+1]
// 2. Bilinear:
float t_v   = (V - table.V[iv]) / (table.V[iv+1] - table.V[iv]);
float t_thr = (throttle - table.throttle[it]) / (table.throttle[it+1] - table.throttle[it]);

float T00 = table.thrust[iv][it];
float T10 = table.thrust[iv+1][it];
float T01 = table.thrust[iv][it+1];
float T11 = table.thrust[iv+1][it+1];

float thrust = Mathf.Lerp(
    Mathf.Lerp(T00, T10, t_v),
    Mathf.Lerp(T01, T11, t_v),
    t_thr
);
// Same for power.
// RPM: linear map throttle → [idle_rpm, max_rpm].
```
